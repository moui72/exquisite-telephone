On larger viewports, the drawing canvas can be focused/expanded to a bigger drawing surface than the default layout allows, giving more room to draw.
Why: on desktop and tablet the default view leaves the canvas smaller than the available space; a focus mode reclaims that space for finer, larger drawings. Small/mobile viewports are unaffected.
