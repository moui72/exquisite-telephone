Host settings offer drawing-tool controls alongside the monochrome decree: a choice of color-palette presets (primary colors plus black and white, the current palette, or a more extensive palette) and a toggle permitting or forbidding the fill tool.
Why: hosts already shape the drawing experience via Room.monochromeOnly; these extend the same lever from one boolean to a set of grouped constraints, so a room can be tuned rather than only stripped of color.
