Clicking the displayed room code copies the bare code to the clipboard, and a context menu (right-click / long-press) adds a "copy join link" option that copies a shareable URL which pre-fills the room when opened.
Why: sharing a room today means reading the code aloud or retyping it; one-tap copy plus a ready-made join link removes that friction, especially on mobile. The join-link option may require a URL-param join path that doesn't exist yet — a design question for planning.
